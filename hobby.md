# Мой пет-проект

Идея: телеграм-бот для учёта расходов
Стек: Python
Цель: научиться работать с Telegram Bot API и базами данных

## Минимальный функционал (MVP)
1. Добавление расхода — пользователь пишет сумму и категорию
2. Просмотр статистики за месяц — сумма по категориям
3. Экспорт в CSV — выгрузка всех расходов за период

## Сроки реализации
- MVP: 1 месяц
- Базовые функции: 2 месяца
- Публикация: конец семестра
