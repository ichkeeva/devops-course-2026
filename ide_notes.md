# Git в VS Code vs терминал

## Что удобно в VS Code
1. Визуальный diff — сразу видно, какие строки добавлены (зелёные) и удалены (красные), не нужно читать вывод git diff.
2. Панель Source Control показывает все изменённые файлы и позволяет коммитить одним кликом — удобно, когда делаешь много мелких правок.
3. GitLens показывает, кто и когда редактировал каждую строку (аналог git blame, но в интерфейсе), и позволяет посмотреть историю файла прямо в редакторе.

## Что удобнее в терминале
- Интерактивный rebase (`git rebase -i`) — в VS Code его нет, а в терминале он открывается в редакторе и даёт полный контроль над коммитами: можно squash, reword, edit, drop.
